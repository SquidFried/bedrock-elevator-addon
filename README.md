# Elevator Addon

A custom elevator addon for Minecraft Bedrock Edition.

## Target version
Minecraft Bedrock 1.26.0.02

## Features planned
- Player-built elevator cabins
- Vertical chain system
- Side-mounted elevator mechanism
- Customizable floor stops
- Floor selection interface
- Modular mirror blocks with player reflection
- Custom textures and sounds

## Development
The addon is being developed independently using JavaScript and Minecraft Script API.

## Status
Early development — prototype stage.
